# **App Name**: Legal Compass

## Core Features:

- User Authentication: User authentication with signup and sign-in functionality to personalize the experience.
- Landing Page: A landing page with a visually appealing design that introduces the app and its purpose.
- Information Repository: Categorized articles and guides explaining various legal topics and rights.
- AI Legal Assistant: An AI-powered tool that answers user questions about basic legal concepts and rights. The tool uses its reasoning capabilities to determine which pieces of information are relevant. All responses are restricted to Indian legal information.
- Intuitive Navigation: A user-friendly interface for easy navigation and access to legal information.
- Document Clarification: Allows users to upload legal documents, clarifies doubts, and provides assistance with the document using AI. All responses are restricted to Indian legal information.
- Previous Queries: Allows users to see previous queries in the sidebar so that they can continue with that chat any time.

## Style Guidelines:

- Primary color: Deep blue (#003366) to convey trust and authority.
- Secondary color: Light gray (#f0f0f0) for a clean and modern background.
- Accent: Teal (#008080) for interactive elements and highlights.
- Clean and structured layout with clear sections for easy readability.
- Use of simple, professional icons to represent different legal topics.
- Subtle transitions and animations to enhance user experience.
